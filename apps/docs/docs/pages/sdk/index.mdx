# SDK Overview

:::note[Audience]
This page is for **Developers** building applications with Shinobi Cash.
:::

Shinobi Cash SDK packages for building privacy-enabled applications.

## Packages

| Package | Purpose | Peer Dependencies |
|---------|---------|-------------------|
| `@shinobi-cash/core` | Crypto, ZK proofs, types | viem, snarkjs |
| `@shinobi-cash/constants` | ABIs, addresses, configs | viem |
| `@shinobi-cash/data` | Indexer client, queries | None |

## Package Hierarchy

```
@shinobi-cash/constants  ← Pure constants (no runtime deps)
        ↓
@shinobi-cash/core       ← Crypto primitives (uses constants)
        ↓
@shinobi-cash/data       ← Indexer queries (uses core types)
```

All packages are **framework-agnostic** and work in any JavaScript/TypeScript environment.

## Installation

```bash
# All packages
npm install @shinobi-cash/core @shinobi-cash/constants @shinobi-cash/data

# Or individually
npm install @shinobi-cash/core
npm install @shinobi-cash/constants
npm install @shinobi-cash/data
```

## Quick Example

### Deriving a Deposit Commitment

```typescript
import {
  derivePrecommitment,
  deriveNoteCommitmentHash
} from '@shinobi-cash/core'
import { SHINOBI_CASH_POOL_ADDRESS } from '@shinobi-cash/constants'

// Derive deposit parameters
const { precommitment, accountSecret, nullifier } = derivePrecommitment({
  accountMasterKey: userKey,
  poolAddress: SHINOBI_CASH_POOL_ADDRESS,
  depositIndex: 0n,
})

// Compute the commitment hash for the smart contract
const commitment = deriveNoteCommitmentHash({
  precommitment,
  value: 1000000000000000000n, // 1 ETH in wei
})
```

### Querying Notes from Indexer

```typescript
import { IndexerClient, DepositQueryBuilder } from '@shinobi-cash/data'

const client = new IndexerClient({
  baseUrl: 'https://indexer.shinobi.cash'
})

// Fetch all deposits for a pool
const query = new DepositQueryBuilder()
  .pool(poolAddress)
  .first(100)
  .build()

const deposits = await client.query(query)
```

### Generating a Withdrawal Proof

```typescript
import {
  generateWithdrawalProof,
  createWithdrawProofInputs
} from '@shinobi-cash/core'

// Prepare proof inputs (note details, merkle paths, etc.)
const inputs = createWithdrawProofInputs({
  note,
  merklePath,
  aspPath,
  withdrawParams,
})

// Generate Groth16 proof
const proof = await generateWithdrawalProof(inputs)
```

## What Each Package Provides

### @shinobi-cash/core

The core cryptographic library:

- **Authentication** — Key derivation, signatures, encryption
- **Deposits** — Precommitment generation, commitment hashing
- **Withdrawals** — Proof inputs, context hashing, fee calculations
- **Note Discovery** — Brute-force discovery of encrypted notes
- **Proof Generation** — Groth16 proofs via snarkjs

[Learn more →](/sdk/core)

### @shinobi-cash/constants

Pure constants with no runtime dependencies:

- **ABIs** — All contract interfaces
- **Addresses** — Pool, entrypoint, settlers, paymasters
- **Chain Configs** — Supported networks (Arbitrum, Base)
- **Gas Limits** — Proof verification, cross-chain operations
- **Fee Constants** — Relay fees, solver fees, compliance fees

[Learn more →](/sdk/constants)

### @shinobi-cash/data

Indexer client and query utilities:

- **IndexerClient** — HTTP client for the indexer API
- **Query Builders** — Fluent APIs for deposits, withdrawals, intents
- **Types** — API response types, serializers
- **Merkle Proofs** — Proof fetching for note paths

[Learn more →](/sdk/data)

## Requirements

- **Node.js** 18+ (recommended 20+)
- **TypeScript** 5+ (recommended)
- **Peer Dependencies:**
  - `viem ^2.0.0` (for core and constants)
  - `snarkjs` (for core proof generation)

## Browser Support

All packages work in modern browsers. For proof generation, you'll need:

```typescript
// Load proof artifacts (circuit files)
const wasmUrl = '/circuits/withdraw.wasm'
const zkeyUrl = '/circuits/withdraw_final.zkey'

// Generate proof
const proof = await generateWithdrawalProof(inputs, wasmUrl, zkeyUrl)
```
