# @shinobi-cash/constants

:::note[Audience]
This page is for **Developers** building applications with Shinobi Cash.
:::

Chain configurations, contract addresses, and ABIs for Shinobi Cash.

## Installation

```bash
npm install @shinobi-cash/constants
```

**Peer dependencies:** `viem ^2.0.0`

## Overview

This package contains pure constants with no runtime dependencies. It exports:

- Contract ABIs
- Contract addresses
- Chain configurations
- Gas limits
- Fee constants

## Chain Configuration

### Supported Chains

```typescript
import {
  POOL_CHAIN,
  ORIGIN_CHAIN,
  SHINOBI_CASH_SUPPORTED_CHAINS
} from '@shinobi-cash/constants'

// Pool chain - where the privacy pool lives
console.log(POOL_CHAIN.id)     // 421614 (Arbitrum Sepolia)
console.log(POOL_CHAIN.name)   // 'Arbitrum Sepolia'

// Origin chain - where users deposit from
console.log(ORIGIN_CHAIN.id)   // 84532 (Base Sepolia)
console.log(ORIGIN_CHAIN.name) // 'Base Sepolia'

// All supported chains
SHINOBI_CASH_SUPPORTED_CHAINS.forEach(chain => {
  console.log(chain.id, chain.name)
})
```

### Chain IDs

```typescript
import {
  POOL_CHAIN_ID,
  ORIGIN_CHAIN_ID,
  DESTINATION_CHAIN_IDS
} from '@shinobi-cash/constants'

// Pool chain
const poolChainId = POOL_CHAIN_ID  // 421614n

// Origin chains for deposits
const originChainId = ORIGIN_CHAIN_ID  // 84532n

// All valid destination chains
const isValidDestination = DESTINATION_CHAIN_IDS.includes(chainId)
```

## Fee Constants

### Basis Points

All fees are expressed in basis points (BPS), where 10000 = 100%.

```typescript
import {
  MAX_RELAY_FEE_BPS,
  DEFAULT_RELAY_FEE_BPS,
  DEFAULT_SOLVER_FEE_BPS,
  COMPLIANCE_FEE_BPS,
} from '@shinobi-cash/constants'

// Maximum relay fee (prevents griefing)
const maxRelay = MAX_RELAY_FEE_BPS  // 2500n (25%)

// Default fees
const defaultRelay = DEFAULT_RELAY_FEE_BPS  // 1500n (15%)
const solverFee = DEFAULT_SOLVER_FEE_BPS    // 100n (1%)
const complianceFee = COMPLIANCE_FEE_BPS    // 50n (0.5%)
```

### Fee Calculations

```typescript
import { MAX_RELAY_FEE_BPS } from '@shinobi-cash/constants'

// Calculate fee amount
const amount = parseEther('1')
const relayFeeBPS = 1500n
const relayFee = (amount * relayFeeBPS) / 10000n
// 0.15 ETH
```

## Using with viem

```typescript
import { createPublicClient, http } from 'viem'
import {
  POOL_CHAIN,
  SHINOBI_CASH_POOL_ADDRESS,
  SHINOBI_CASH_POOL_ABI,
  POOL_CHAIN_RPC_URL,
} from '@shinobi-cash/constants'

const client = createPublicClient({
  chain: POOL_CHAIN,
  transport: http(POOL_CHAIN_RPC_URL),
})

const scope = await client.readContract({
  address: SHINOBI_CASH_POOL_ADDRESS,
  abi: SHINOBI_CASH_POOL_ABI,
  functionName: 'SCOPE',
})
```
