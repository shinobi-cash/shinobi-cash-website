## Overview

Chain configurations, contract addresses, and ABIs.

## Installation

```bash
npm install @shinobi-cash/constants
```

## Key Exports

### Chain Configuration

```typescript
import {
  POOL_CHAIN,
  ORIGIN_CHAIN,
  SHINOBI_CASH_SUPPORTED_CHAINS
} from '@shinobi-cash/constants'

// Pool chain (Arbitrum Sepolia)
console.log(POOL_CHAIN.id) // 421614

// Origin chain (Base Sepolia)
console.log(ORIGIN_CHAIN.id) // 84532
```
