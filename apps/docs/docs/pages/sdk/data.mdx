# @shinobi-cash/data

:::note[Audience]
This page is for **Developers** building applications with Shinobi Cash.
:::

Indexer client and query utilities for Shinobi Cash.

## Installation

```bash
npm install @shinobi-cash/data
```

No peer dependencies required.

## Overview

This package provides:

- **IndexerClient** — HTTP client for the indexer API
- **Query Builders** — Fluent APIs for building queries
- **Types** — API response types and serializers
- **Utilities** — Merkle proof fetching, pagination

## IndexerClient

The main client for interacting with the Shinobi Cash indexer.

### Creating a Client

```typescript
import { IndexerClient } from '@shinobi-cash/data'

const client = new IndexerClient({
  baseUrl: 'https://indexer.shinobi.cash',
  timeout: 30000,  // optional, defaults to 30s
})
```

### Basic Queries

```typescript
// Get deposits for a pool
const deposits = await client.getDeposits({
  pool: poolAddress,
  first: 100,
})

// Get withdrawal by nullifier
const withdrawal = await client.getWithdrawal({
  nullifier: nullifierHash,
})

// Get pool statistics
const stats = await client.getPoolStats(poolAddress)
```

## Query Builders

Fluent APIs for building complex queries.

### DepositQueryBuilder

```typescript
import { DepositQueryBuilder } from '@shinobi-cash/data'

const query = new DepositQueryBuilder()
  .pool(poolAddress)
  .after(lastCursor)
  .first(50)
  .orderBy('blockNumber', 'desc')
  .build()

const deposits = await client.query(query)
```

### Available Methods

| Method | Description |
|--------|-------------|
| `.pool(address)` | Filter by pool address |
| `.depositor(address)` | Filter by depositor (cross-chain only) |
| `.after(cursor)` | Pagination cursor |
| `.first(n)` | Limit results |
| `.orderBy(field, dir)` | Sort results |
| `.build()` | Build the query object |

### WithdrawalQueryBuilder

```typescript
import { WithdrawalQueryBuilder } from '@shinobi-cash/data'

const query = new WithdrawalQueryBuilder()
  .pool(poolAddress)
  .recipient(recipientAddress)
  .first(100)
  .build()

const withdrawals = await client.query(query)
```

### IntentQueryBuilder

```typescript
import { IntentQueryBuilder } from '@shinobi-cash/data'

const query = new IntentQueryBuilder()
  .status('pending')
  .destinationChain(84532n)
  .first(20)
  .build()

const intents = await client.query(query)
```

### Intent Status Values

| Status | Description |
|--------|-------------|
| `pending` | Intent created, awaiting fill |
| `filled` | Solver filled the intent |
| `claimed` | Solver claimed funds on origin |
| `refunded` | Intent expired and refunded |

## Pagination

### Cursor-Based Pagination

```typescript
let cursor: string | undefined
const allDeposits: IndexedDeposit[] = []

do {
  const query = new DepositQueryBuilder()
    .pool(poolAddress)
    .after(cursor)
    .first(100)
    .build()

  const { deposits, pageInfo } = await client.queryWithPageInfo(query)
  allDeposits.push(...deposits)
  cursor = pageInfo.endCursor
} while (cursor)
```

### Page Info

```typescript
interface PageInfo {
  hasNextPage: boolean
  hasPreviousPage: boolean
  startCursor?: string
  endCursor?: string
}
```

## Subscriptions

Real-time updates via WebSocket (where supported).

```typescript

  pool: poolAddress,

subscription.unsubscribe()
```

## Error Handling

```typescript
import { IndexerError, NetworkError } from '@shinobi-cash/data'

try {
  const deposits = await client.getDeposits({ pool: poolAddress })
} catch (error) {
  if (error instanceof NetworkError) {
    // Network/connection issue
    console.error('Network error:', error.message)
  } else if (error instanceof IndexerError) {
    // Indexer returned an error
    console.error('Indexer error:', error.code, error.message)
  }
}
```

### Error Types

| Error | Description |
|-------|-------------|
| `NetworkError` | Connection failed, timeout |
| `IndexerError` | Indexer returned error response |
| `ValidationError` | Invalid query parameters |

## Usage with React Query

```typescript
import { useQuery } from '@tanstack/react-query'
import { IndexerClient, DepositQueryBuilder } from '@shinobi-cash/data'

const client = new IndexerClient({
  baseUrl: 'https://indexer.shinobi.cash'
})

function useDeposits(poolAddress: Address) {
  return useQuery({
    queryKey: ['deposits', poolAddress],
    queryFn: async () => {
      const query = new DepositQueryBuilder()
        .pool(poolAddress)
        .first(100)
        .build()
      return client.query(query)
    },
  })
}
```
