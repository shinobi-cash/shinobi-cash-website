## Overview

Extended Privacy Pool with cross-chain withdrawal support.

## Key Responsibilities

- Commitment insertion (deposits)
- Nullifier spending (withdrawals)
- ZK proof verification (8-signal standard, 9-signal cross-chain)
- Refund commitment handling

## Key Functions

```solidity
// Process cross-chain withdrawal with 9-signal proof
function crosschainWithdraw(
    Withdrawal memory _withdrawal,
    CrossChainProofLib.CrossChainWithdrawProof memory _proof
) external

// Handle refund for failed cross-chain withdrawal
function handleRefund(
    uint256 _refundCommitmentHash,
    uint256 _amount
) external payable onlyEntrypoint
```
